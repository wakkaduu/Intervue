# Intervue gallery captions

Screenshots of the running app, 1440 x 960. The sessions behind images 06 to 08 were played with scripted
sample answers; the reviews are live AI output.

| File | Caption |
| --- | --- |
| 01-home.png | Start in one step: choose a track, choose voice or written, and start practicing. |
| 02-feedback-example.png | An example review on the home page: the interviewer's take, one thing to work on first, a stronger way to say it, and the follow-up question. |
| 03-track-picker.png | The track picker groups 52 tracks by field, with a search box and filters. |
| 04-voice-setup.png | Voice mode explains how the session works and offers an optional microphone check before the first question. |
| 05-written-answer.png | The question comes first, the interviewer can read it aloud, and the draft saves itself while the timer runs. |
| 06-results.png | After the last question every answer is reviewed. The results page shows a score, a plain verdict, and an AI debrief written across all the answers. |
| 06b-debrief.png | The debrief finds patterns across answers, points to the best and weakest one, and lists what to fix first. |
| 07-coaching.png | Each answer gets one thing to work on first, a stronger way to say it with placeholders for real numbers, the follow-up a real interviewer would ask, and the interviewer's take. |
| 08-history.png | The History page charts the average score of each practice session, with a table view and a plain note on how much you improved. |
| 09-signin.png | Accounts are optional: guests practice freely and sign up later to keep their history across devices. |
| 10-phone.png | The same flow on a phone: home, a question, and results, with large touch targets and a next action that stays in reach. |
